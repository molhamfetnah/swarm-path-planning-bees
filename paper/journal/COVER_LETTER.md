\section*{Why This Paper Fits Applied Soft Computing}

This paper presents a modernized implementation of the Bees Algorithm—a nature-inspired optimization technique—for robot path planning in dynamic environments. The work directly aligns with the journal's scope in:

\begin{itemize}
    \item \textbf{Intelligent optimization algorithms} - Novel extensions to the Bees Algorithm
    \item \textbf{Soft computing applications} - Multi-objective optimization for robotics
    \item \textbf{Real-world applications} - Path planning with dynamic obstacle avoidance
\end{itemize}

\section*{Key Contributions}

\begin{enumerate}
    \item Adaptive parameter tuning based on convergence state
    \item Multi-objective optimization (path length, safety, smoothness, energy)
    \item Real-time dynamic obstacle handling
    \item Comprehensive benchmark evaluation (100\% success rate across 6 scenarios)
    \item Open-source implementation available on GitHub
\end{enumerate}
