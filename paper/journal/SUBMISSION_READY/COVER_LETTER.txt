WHY THIS PAPER FITS APPLIED SOFT COMPUTING
------------------------------------------
This paper presents a modernized implementation of the Bees Algorithm—a nature-inspired optimization technique—for robot path planning in dynamic environments. The work directly aligns with the journal's scope in:

- Intelligent optimization algorithms - Novel extensions to the Bees Algorithm
- Soft computing applications - Multi-objective optimization for robotics
- Real-world applications - Path planning with dynamic obstacle avoidance

KEY CONTRIBUTIONS
-----------------
1. Adaptive parameter tuning based on convergence state
2. Multi-objective optimization (path length, safety, smoothness, energy)
3. Real-time dynamic obstacle handling
4. Comprehensive benchmark evaluation (100% success rate across 6 scenarios)
5. Open-source implementation available on GitHub
